# Screenshots

These portfolio views use a dedicated demonstration database. The account and all inventory, consumption and waste values are fictional. The views illustrate the software workflow and do not describe the café’s operations or impact.

| View | What it demonstrates |
| --- | --- |
| Sustainability dashboard | Period filters and separate consumption and discard totals by unit |
| Inventory | Stock levels, minimum thresholds and movement history |

To recreate the views, follow the [local development guide](DEVELOPMENT.md). Use an empty demo database and a reserved address such as `demo@example.com`. Add demo coffee beans in kilograms and cups in units, then record a fictional consumption and discard for the beans. Capture the app viewport and review it for visible identifiers, real records and environment details before sharing.
